## GPDS

## Funciones principales
* Registrar productos
* Consultar
* Contar el total de productos
* Visualizar el estado del producto

## Tecnologias
* PHP 8.4.16 
* SQL-Maria DB
* CSS 3
* HTML 5

## Instalar
* XAMP v.3.0
* HeidiSQL v12.10.0.700
* Visual Studio Code v18.5.0
* extencion de php
* Un navegador

## Configuracion y Instalacion
* Activa XAMP
* Ejecuta el codigo de creacion de la base de datos en HeidiSQL 
* Abre la carpeta del proyecto en visual studio code
* En el proyecto, en el archivo de conexiones comprueba que las credenciales sean correctas
* Ahora desde la raiz del main del proyecto ejecutando un servidor (Local) desde el index usando la herramienta de visual studio code
* E ingresa en la direccion: http://localhost:8000 desde el navegador de tu preferencia
